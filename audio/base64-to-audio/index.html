Base64 to Audio

Decode a Base64 string or data URI back into a playable, downloadable audio file. Nothing is uploaded.

MP3WAVFLACAAC/M4AOGG no file needed 100 MB / file

How this tool works without JavaScript

Paste a Base64 string or a full data URI and Bench reconstructs the original audio bytes for playback and download.

Enable JavaScript to use the interactive tool. Processing happens locally in your browser; nothing is uploaded.

What it does

Paste a Base64 string or a full data URI and Bench reconstructs the original audio bytes for playback and download.

How to use

  1. Paste a Base64 string or data URI.
  2. Run the tool. Bench detects the audio type from the data URI or the file signature.
  3. Play or download the reconstructed file.

Common use cases

  • Recover an audio file pasted from an API response.
  • Test a data URI.

Limits & considerations

A bare Base64 payload without a data URI may not carry a MIME type; Bench then guesses from the decoded bytes.

How your audio is processed

This tool uses the Web Audio API directly in your browser for decoding, analysis and export. No audio leaves your device.

Privacy & security

Decoding, editing and encoding run inside your browser. Files are read from local memory into temporary object URLs and are never uploaded, logged or stored by Bench. The FFmpeg.wasm engine is downloaded once from this site (same origin) and runs entirely on your device.

Frequently asked questions

Is my file uploaded?

No. Processing happens in your browser and the file is never sent to Bench or a third party.
