Status and limits

Implemented tools are covered by automated tests and produce real files. Experimental tools run real signal processing but have documented quality caveats; their results should be checked before important use. Limits: 100 MB per file, 30 minutes per file, 20 files per batch. Conversion and complex filters use a 31 MB FFmpeg engine downloaded once and cached.

How processing works

Simple editing, analysis, recording and WAV export use the Web Audio API directly in the tab. Format conversion and complex filters (loudness normalisation, denoise, speed, EQ) use a WebAssembly build of FFmpeg that runs on your device. Either way, the audio bytes never leave your machine and Bench keeps no copy.

Licences and source

The FFmpeg engine shipped here is the official @ffmpeg/core build, licensed under the GNU General Public License v2.0 or later. It is served unmodified from this site at /vendor/ffmpeg/ and is never loaded from a third-party CDN. The JavaScript wrapper (@ffmpeg/ffmpeg) is MIT licensed.

Full attributions, exact version numbers and a written offer to supply the corresponding source code are published in /vendor/ffmpeg/NOTICE.txt. That notice names the upstream FFmpeg project and the ffmpeg.wasm packaging project, including their source repositories.

Not available yet

These entries exist so the catalogue stays honest. No page is generated for them and no upload control is offered.

Audio TranscriptionDeferred

Requires a speech-recognition model (e.g. Whisper). Running it in-browser needs a large model download and the site's CSP blocks external APIs (connect-src 'self'). Ship a verified adapter before publishing a page.

Text to SpeechUnavailable

The browser SpeechSynthesis API can speak text but cannot reliably capture the output to a file, so a real downloadable MP3/WAV is not possible without a TTS engine or provider. Not offered rather than faked.

Vocal Remover / Stem SeparationDeferred

Requires a real source-separation model (e.g. Demucs/Spleeter). A centre-channel cancellation is not genuine separation, so this is deferred until a licensed model can be shipped.

AI Noise ReductionDeferred

Requires a licensed neural model. The shipped afftdn denoiser is real spectral processing, not AI, and is offered honestly as the Noise Reducer instead.

Audio RestorationDeferred

Needs a restoration model. Deterministic filters (declick, declip) exist in the engine and could ship as an experimental tool; full restoration is deferred.

Speaker DiarizationUnavailable

Depends on a speaker-recognition model and, typically, a transcript. No local model is shipped, so labels cannot be produced from real results.

Speech TranslationDeferred

Depends on transcription plus a translation service. External APIs are blocked by the site's CSP, so this is deferred with transcription.

System / Tab Audio CaptureDeferred

getDisplayMedia with audio capture is not supported consistently across browsers and platforms. Deferred rather than shipped with silent failures.
