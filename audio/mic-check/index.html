How this tool works without JavaScript

Lists your audio input devices, shows a real-time input level meter and a peak-hold readout so you can confirm the microphone and gain before recording.

Enable JavaScript to use the interactive tool. Processing happens locally in your browser; nothing is uploaded.

What it does

Lists your audio input devices, shows a real-time input level meter and a peak-hold readout so you can confirm the microphone and gain before recording.

How to use

  1. Click Start test and allow microphone access.
  2. Speak and watch the level meter and peak hold.
  3. Read the device and permission status.

Common use cases

  • Check a headset before a call.
  • Set the right input gain.

Limits & considerations

Some browsers hide device labels until permission is granted. The meter reads the raw input, not post-processing.

How your audio is processed

The microphone is opened by the browser only after you press start, and the captured audio stays in local memory. Bench never receives or stores the recording.

Privacy & security

Recording uses the browser MediaRecorder API. Your audio is captured from the microphone into local memory, is never uploaded and is discarded when you leave the page or clear it. Bench does not retain recordings.

Frequently asked questions

Is my file uploaded?

No. Processing happens in your browser and the file is never sent to Bench or a third party.
