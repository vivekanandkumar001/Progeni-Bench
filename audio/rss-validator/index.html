How this tool works without JavaScript

Parses the RSS XML you paste, checks each item's enclosure for a URL, a length and a valid audio MIME type, and reports the problems that break podcast apps.

Enable JavaScript to use the interactive tool. Processing happens locally in your browser; nothing is uploaded.

What it does

Parses the RSS XML you paste, checks each item's enclosure for a URL, a length and a valid audio MIME type, and reports the problems that break podcast apps.

How to use

  1. Paste your RSS XML.
  2. Run the validator.
  3. Fix the enclosure issues it reports.

Common use cases

  • Debug a podcast feed rejected by Spotify.
  • Check enclosures before publishing.

Limits & considerations

Validates structure, not reachability; it does not download the audio URLs. Only well-formed XML is parsed.

How your audio is processed

This tool uses the Web Audio API directly in your browser for decoding, analysis and export. No audio leaves your device.

Privacy & security

Decoding, editing and encoding run inside your browser. Files are read from local memory into temporary object URLs and are never uploaded, logged or stored by Bench. The FFmpeg.wasm engine is downloaded once from this site (same origin) and runs entirely on your device.

Frequently asked questions

Is my file uploaded?

No. Processing happens in your browser and the file is never sent to Bench or a third party.
