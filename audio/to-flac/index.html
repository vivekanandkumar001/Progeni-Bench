How this tool works without JavaScript

FLAC stores every sample of the original with lossless compression, so it is typically 40-60% smaller than WAV while remaining a perfect copy of the source audio.

Enable JavaScript to use the interactive tool. Processing happens locally in your browser; nothing is uploaded.

What it does

FLAC stores every sample of the original with lossless compression, so it is typically 40-60% smaller than WAV while remaining a perfect copy of the source audio.

How to use

  1. Add a lossless source such as WAV or AIFF for a true lossless result.
  2. Keep channels and sample rate, or adjust them.
  3. Run the encoder and download the FLAC file.

Common use cases

  • Archive recordings losslessly.
  • Halve a WAV's size without losing quality.

Limits & considerations

Encoding a lossy source to FLAC keeps the lossy artefacts - FLAC preserves what you give it, it cannot restore detail. FLAC is not supported by every legacy device.

How your audio is processed

This tool encodes with the FFmpeg engine running as WebAssembly inside your browser. The engine is downloaded once (about 31 MB) and cached; the audio is processed locally and is never uploaded.

Privacy & security

Decoding, editing and encoding run inside your browser. Files are read from local memory into temporary object URLs and are never uploaded, logged or stored by Bench. The FFmpeg.wasm engine is downloaded once from this site (same origin) and runs entirely on your device.

Frequently asked questions

Is my file uploaded?

No. Processing happens in your browser and the file is never sent to Bench or a third party.
