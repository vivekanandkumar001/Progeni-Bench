Audio to WAV

Decode any supported audio file and export a universally compatible, uncompressed WAV file. Nothing is uploaded.

How this tool works without JavaScript

Uses the browser's own decoder to turn your audio into uncompressed PCM WAV. WAV plays everywhere and is the safest format for editing, at the cost of a large file.

Enable JavaScript to use the interactive tool. Processing happens locally in your browser; nothing is uploaded.

What it does

Uses the browser's own decoder to turn your audio into uncompressed PCM WAV. WAV plays everywhere and is the safest format for editing, at the cost of a large file.

How to use

  1. Add any audio file your browser can decode.
  2. Choose channels and sample rate, or keep the originals.
  3. Bench writes a standard 16-bit PCM WAV and offers it for download.

Common use cases

  • Prepare audio for a video editor.
  • Convert a compressed file for a CD or hardware device.

Limits & considerations

WAV is uncompressed, so files are large (roughly 10 MB per minute of stereo 44.1 kHz). Sample rates above the source offer no real gain.

How your audio is processed

This tool uses the Web Audio API directly in your browser for decoding, analysis and export. No audio leaves your device.

Privacy & security

Decoding, editing and encoding run inside your browser. Files are read from local memory into temporary object URLs and are never uploaded, logged or stored by Bench. The FFmpeg.wasm engine is downloaded once from this site (same origin) and runs entirely on your device.

Frequently asked questions

Is my file uploaded?

No. Processing happens in your browser and the file is never sent to Bench or a third party.
