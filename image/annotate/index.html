How this tool works without JavaScript

Add a caption, label, callout text or a caption bar to an image with real canvas rendering.

Enable JavaScript to use the interactive tool. Processing happens locally in your browser; nothing is uploaded.

What it does

Add a caption, label, callout text or a caption bar to an image with real canvas rendering.

How to use

  1. Upload an image and type the text.
  2. Choose top, centre, bottom or a custom position, then set the font size and colours.
  3. Add a caption bar by entering a background colour; leave it blank for outlined text only.
  4. Run the annotation and download the rendered image.

Common use cases

  • Caption a screenshot for documentation.
  • Add a name label to a photo.
  • Create a simple quote graphic.

Limits & considerations

Text is rendered as pixels, not editable layers. The tool supports a single text block per run and uses the browser's available sans-serif font. Emoji rendering depends on the operating system. Line breaks are preserved but long lines are wrapped to the image width.

Privacy & security

Decoding, editing and encoding all run inside your browser using Canvas and File APIs. The file is never uploaded, logged or stored by Bench, and the result exists only in a temporary object URL until you download it or close the page.
