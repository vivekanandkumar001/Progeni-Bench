How this tool works without JavaScript

Generate CODE128, EAN-13, EAN-8, CODE39 or UPC-A barcodes as real PNG images with validation.

Enable JavaScript to use the interactive tool. Processing happens locally in your browser; nothing is uploaded.

What it does

Generate CODE128, EAN-13, EAN-8, CODE39 or UPC-A barcodes as real PNG images with validation.

How to use

  1. Enter the value and choose the barcode format.
  2. Set bar width, height, colours and whether to show the value.
  3. Generate; invalid checksums or characters are reported instead of drawing a misleading code.
  4. Download the PNG and verify it with the scanner used by your workflow.

Common use cases

  • Make an internal asset label.
  • Create an EAN-13 graphic from a valid number.
  • Produce a CODE128 barcode for a shipping label.

Limits & considerations

The tool generates barcodes but does not read them. EAN/UPC check digits are validated but not certified by GS1. Code 128 support covers the browser library's standard character set. Always test a generated barcode with the actual scanner before printing a production run.

Privacy & security

Decoding, editing and encoding all run inside your browser using Canvas and File APIs. The file is never uploaded, logged or stored by Bench, and the result exists only in a temporary object URL until you download it or close the page.
