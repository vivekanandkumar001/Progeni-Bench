Enable JavaScript to use the interactive tool. Processing happens locally in your browser; nothing is uploaded.

What it does

Rename a batch of images with a numbered pattern and optionally convert format, then download everything as a ZIP.

How to use

  1. Add images in the order they should be numbered.
  2. Enter a pattern such as product-{n}; {n} is replaced with a zero-padded sequence.
  3. Choose keep-source or a conversion format.
  4. Run the batch and download the ZIP. Duplicate or unsafe names are sanitised automatically.

Common use cases

  • Rename product photos for an upload form.
  • Create a numbered photo sequence.
  • Standardise a mixed-format batch.

Limits & considerations

Renaming happens only inside the ZIP download; files on your disk are not modified. Sequence numbers are assigned in the listed order. The ZIP is generated in browser memory and should be kept under the batch limits.

Privacy & security

Decoding, editing and encoding all run inside your browser using Canvas and File APIs. The file is never uploaded, logged or stored by Bench, and the result exists only in a temporary object URL until you download it or close the page.
