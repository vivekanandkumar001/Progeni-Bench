What it does

Hit a 10 KB, 20 KB, 50 KB, 100 KB, 200 KB, 500 KB, 1 MB or custom size by searching quality and, if allowed, dimensions.

How to use

  1. Upload the image and enter the exact target in kilobytes. Preset targets are shown in the field help.
  2. Choose JPEG, WebP or AVIF. Leave downscaling enabled unless the required pixel dimensions are fixed.
  3. Start the search. Bench tests real encodings, narrows in on quality and only reduces dimensions when necessary.
  4. Check the achieved size and the note. If the target cannot be met without dropping below your minimum quality, the tool says so instead of hiding it.

Common use cases

  • Meet a government form upload limit in kilobytes.
  • Prepare a thumbnail below a strict CDN limit.
  • Reduce a photo for an email attachment without guessing the quality slider.

Limits & considerations

A target size is reached by actually re-encoding, so the result may be slightly under or over the goal. PNG is lossless and cannot be quality-tuned, so target-size search is not offered for PNG. Very small targets on large photos can require substantial downscaling. Application forms that demand exact pixels should keep downscaling disabled.

Privacy & security

Decoding, editing and encoding all run inside your browser using Canvas and File APIs. The file is never uploaded, logged or stored by Bench, and the result exists only in a temporary object URL until you download it or close the page.
