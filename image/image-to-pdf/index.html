Enable JavaScript to use the interactive tool. Processing happens locally in your browser; nothing is uploaded.

What it does

Combine JPEG, PNG, WebP or rasterised SVG images into a single PDF, one page per image or fitted to A4/Letter.

How to use

  1. Add images in the order you want them to appear. The file list is processed in that order.
  2. Choose image-sized pages for exact aspect ratios, or A4/Letter for a document with optional margins.
  3. Set the internal JPEG quality. Higher quality makes a larger PDF.
  4. Run the export and download the finished PDF. Pages are assembled locally from real JPEG image streams.

Common use cases

  • Turn a set of photos into one document.
  • Package scanned pages for email.
  • Create a simple portfolio PDF without an upload service.

Limits & considerations

The PDF contains raster images, not searchable text or vector objects. Transparency is flattened onto white. Orientation is taken from the decoded image, so EXIF-rotated phone photos are normalised. A maximum of 40 pages is enforced to keep memory use bounded.

Privacy & security

Decoding, editing and encoding all run inside your browser using Canvas and File APIs. The file is never uploaded, logged or stored by Bench, and the result exists only in a temporary object URL until you download it or close the page.
