How this tool works without JavaScript

Pack images into an evenly spaced sprite sheet with a generated CSS background-position snippet.

Enable JavaScript to use the interactive tool. Processing happens locally in your browser; nothing is uploaded.

What it does

Pack images into an evenly spaced sprite sheet with a generated CSS background-position snippet.

How to use

  1. Add the frames in the order they should appear.
  2. Set columns, cell size and gap. Images are scaled into square cells.
  3. Generate the sheet and the matching CSS.
  4. Download the PNG and copy the CSS snippet into your stylesheet.

Common use cases

  • Create a simple CSS animation sprite.
  • Pack UI icons into one request.
  • Build a game prototype sheet.

Limits & considerations

All cells are square and the same size; images are contained, not cropped. The generated CSS assumes the exact column count and cell size shown in the report. There is no packed/irregular atlas or JSON texture-map export.

Privacy & security

Decoding, editing and encoding all run inside your browser using Canvas and File APIs. The file is never uploaded, logged or stored by Bench, and the result exists only in a temporary object URL until you download it or close the page.
