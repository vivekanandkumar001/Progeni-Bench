Image Studio

A three-step batch recipe for real work: add images, choose one set of export settings, then download every result or a ZIP. Everything runs locally — the files never leave your device.

Quick answer

Image Studio applies one resize, format and quality recipe to up to 30 images, then exports each result or a ZIP. Decoding, cropping, conversion and compression all run locally in your browser.

1. Add images

Drop JPEG, PNG, WebP, GIF, BMP, TIFF, AVIF or SVG files, or use the picker. The live studio shows each preview, dimensions and byte size before you run anything.

2. Choose a recipe

  • Output format: WebP, JPEG or PNG.
  • Maximum width: 0 keeps the original size; the default is 1600 px.
  • Square crop, quality, background colour and metadata stripping.

3. Export

Download each successful result, or take one ZIP containing everything. Files that fail are listed separately and never replaced with a fake success.

Why a studio instead of another page?

Batch resize, batch convert and batch compression share exactly the same decode → transform → encode pipeline. Folding them into one recipe avoids three thin, duplicate pages while keeping the individual single-purpose tools available.

What Image Studio does

Image Studio applies one resize, format and quality recipe to several images at once. It is intended for preparing web images, marketplace photos and consistent documentation. It is not a photo editor: use the individual crop, annotate, watermark and adjustment tools for per-image edits.

Privacy & security

Decoding and encoding use the browser Canvas API. Files are read from local memory, results are temporary object URLs, and no image bytes are sent to Bench or a third party. Object URLs are revoked when results are replaced or the page is left.

Limits

Each file is limited to 50 MB and 40 megapixels. A batch is limited to 30 files and an estimated 160 megapixels of work. Very large or unusual files may still be rejected by the browser decoder; that failure is reported instead of hidden.
