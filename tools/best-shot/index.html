About this tool — how it works, limits & FAQ

What it does

Scores every photo with variance-of-Laplacian sharpness on an aspect-preserving 256 px downsample (letterboxed, never stretched), plus an exposure/clipping penalty and a contrast term. Blends them into a 0-100 composite score with adjustable weights and shows the sharpness/exposure/contrast breakdown per photo, a full ranked list with load-more, and a side-by-side compare of the top shots.

Common use cases

  • Burst Photography Selection: Score multiple rapid-fire takes to identify the single sharpest photo with the crispest subject detail.
  • Group Portrait Quality Assessment: Detect photos with motion blur or camera shake to select the cleanest group picture.
  • Macro & Product Photography Culling: Rank close-up product captures by edge contrast and focal plane clarity.

How to use

  1. Select a batch of burst photos taken in similar lighting from your camera roll.
  2. Each image is downsampled to 256 px, then a 3x3 Laplacian kernel measures sharpness while exposure and contrast are scored.
  3. Inspect the ranked list, per-photo breakdown and compare view, and adjust the weighting sliders to taste.
  4. Export the ranking as CSV or copy the winning filename to keep the crispest frame.

Limits & considerations

Edge-based sharpness and exposure heuristics only — artistic composition and facial expressions are not judged. Unsupported files are skipped and reported instead of stopping the batch.

Frequently asked questions

How is photo sharpness calculated mathematically?

The tool calculates Laplacian edge variance across the luminance channel, where higher edge gradient variance indicates sharper focus.

Does the tool penalize overexposed or clipped highlights?

Yes. The composite scoring model balances edge sharpness with contrast metrics and clipped pixel ratios to avoid overexposed shots.

Can I compare raw score rankings across all uploaded photos?

Yes. The interface ranks photos by composite quality score with visual badges identifying the #1 recommended keeper.

Privacy & security

Pixel data is analyzed inside local Canvas memory buffers without external API calls or machine learning cloud server uploads.
