Family Photo Date Organizer

Organize family photos into a year-to-month-to-day tree and export a rename plan. Zero server uploads — all processing happens directly in your browser.

What it does

Builds a collapsible year → month → day summary tree with per-group counts and a thumbnail contact strip per group, then previews a proposed folder structure from an editable rename pattern (default YYYY/MM/YYYY-MM-DD_title.ext) as a live old-name → new-path table. Dates prefer EXIF DateTimeOriginal, wrong timestamps can be corrected per file or in bulk per group, and every entry carries a date-confidence badge. Since browsers cannot move files on disk, it exports a self-contained family-organizer.html archive index plus a planned-folder CSV and JSON mapping (original → proposed path).

How to use

  1. Select multiple family photos (and any other files) from your hard drive or camera backup.
  2. Photos are dated from EXIF DateTimeOriginal first, then the file date; non-image files still appear in the tree without a thumbnail.
  3. Inspect the year → month → day tree, fix wrong dates per file or in bulk per group, and tune the rename pattern to watch the proposed paths update live.
  4. Download family-organizer.html plus the planned-folder CSV or JSON, then apply the rename plan with your own file manager.

Limits & Considerations

Organizes and renames by date but never rewrites EXIF header tags or moves files on disk — it exports an HTML index and a rename plan instead. Thumbnails require browser-decodable image formats.

Privacy & Security

All photo analysis and document compilation occur inside your local browser sandbox. No family pictures are ever uploaded to external servers.
