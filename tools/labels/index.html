Avery 5160 Label Maker

Build printable Avery 5160, 5163, 5167, L7160 and custom label sheets from CSV, pasted rows, or a single manual label — multi-line builder with live sheet preview. Zero server uploads — all processing happens directly in your browser.

What it does

Runs a full Label Studio engine: verified template geometry (Avery 5160 30-up, 5163 10-up, 5167 80-up return, EU L7160 21-up, name badges and fully custom grids) drives a live canvas preview built from the same layout the exports use, so preview and print always match. A multi-line builder (up to 6 lines) places {{Column}} tokens, sequence numbers, bold/italic/alignment, per-line sizes and auto-shrink overflow on every label; an address wizard detects name, street, city, state and zip columns automatically. Data comes from an uploaded CSV, pasted spreadsheet rows, or manual single-label mode, with a sortable inline-editable data table. Exports: 300 DPI PNG, standalone HTML, or direct print with exact @page sizing.

Common use cases

  • Address & Shipping Labels: Populate Avery 5160 or EU L7160 sheets from customer spreadsheets with automatic column mapping for names, streets, and postal codes.
  • Warehouse & Storage Organization: Generate serial-numbered inventory tags, shelf bin markers, and equipment labels with custom {{Column}} token layouts.
  • Event Badges & Attendee Tags: Create uniform conference badges and table place cards directly from pasted Excel or Google Sheets roster rows.

How to use

  1. Pick your label template (Avery 5160, 5163, 5167, L7160, name badge, or a custom grid) and nudge the calibration offsets if your printer feeds paper off-center.
  2. Load your data: upload a CSV, paste rows copied from Excel or Google Sheets, or skip data entirely to compose a single manual label.
  3. Build the label lines — click column chips to insert {{Column}} tokens, or press the Address wizard to detect and lay out name/address columns automatically.
  4. Fine-tune fonts, alignment, vertical position, repeat mode and overflow policy while watching the live sheet preview, page tabs and sheet-count report.
  5. Export a 300 DPI PNG, download standalone HTML, or open Print for physical output / Save as PDF — always print at 100% / Actual size.

Limits & Considerations

Text-only labels (up to 6 lines per label); QR/Code128 barcodes, logo artwork and UPC/EAN are not yet supported. Print at 100% scale — do not use 'Fit to page'. Margins for the 5163/5167/badge templates are provisional and can be corrected with the ±3 mm calibration offsets or the custom grid.

Frequently Asked Questions

Which Avery label templates are supported natively?

The tool includes verified geometric profiles for Avery 5160 (30-up), 5163 (10-up shipping), 5167 (80-up return address), EU L7160 (21-up on A4), and fully custom label grids.

How do I ensure labels align with physical pre-cut label sheets?

Always configure your printer dialog to 100% scale (or 'Actual Size') without fit-to-page margins, and use the ±3 mm fine calibration offset inputs if your printer feeder drifts.

Is my customer mailing list kept secure and private?

Yes. Your CSV data and pasted rows are parsed purely in browser RAM and are never transmitted, logged, or saved to any cloud database.

Privacy & Security

Your CSV files, pasted rows and mailing lists are parsed purely in your browser and never uploaded. Saved presets store label layout only — row data persists locally only if you explicitly export a JSON project.
