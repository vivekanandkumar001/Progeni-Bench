PDF Translator

Translate text PDFs into other languages, including best-effort Romanized Hindi, and download a readable PDF. PDF pages stay in your browser. Extracted text is sent to DeepL through a server-side endpoint.

Quick answer

PDF Translator is a free files & data tool that runs in your browser. Extracts text in your browser, sends only selected text blocks to DeepL through a private server endpoint, and assembles a downloadable PDF locally.

What it does

Extracts text in your browser, sends only selected text blocks to DeepL through a private server endpoint, and assembles a downloadable PDF locally. It supports best-effort layout reconstruction, clean readable pages, bilingual source-and-translation pages, page ranges, and local OCR for image-only pages.

Common use cases

  • Translate text-based reports, guides and study materials while retaining their page structure where practical.
  • Convert Hindi translations to Roman script for a best-effort Hinglish reading copy.
  • OCR scanned English or Hindi pages locally before translating selected pages.

How to use

  1. Choose a PDF under 15 MB and review its page count and supported-page notice.
  2. Select a target language, translation style and output layout; optionally set a source language and page range.
  3. Enable local OCR for scanned pages. OCR requires downloading language data to your browser, but page images stay on your device.
  4. Translate and review the text preview and page-quality report before downloading the generated PDF.

Limits & Considerations

Maximum 15 MB, 30 pages and 120,000 extracted characters per job. Complex tables, embedded image text, handwriting, unusual fonts and expanded translations can affect layout. Original-layout reconstruction is best-effort, links are not preserved as interactive links, and output pages are rasterized. Hinglish is DeepL Hindi translated then romanized; the mix of Hindi and English is not guaranteed. The translation provider processes extracted text.

Frequently Asked Questions

Is my PDF uploaded to Bench?

No. PDF pages stay in your browser. Extracted text is sent to DeepL through a server endpoint, so the translation provider processes that text.

Does Hinglish use Roman script?

Yes. The tool translates to Hindi and romanizes that output. This is best-effort Romanized Hindi, not guaranteed natural Hindi-English mixing.

Can scanned documents be translated?

Yes, when local OCR is enabled and the required language data is available. OCR may be incomplete for low-quality scans, handwriting and image-heavy pages.

Privacy & Security

The PDF itself is parsed, rendered, OCR-processed and rebuilt locally in your browser. Extracted text blocks are sent to the configured DeepL API through the Bench server endpoint for translation; API credentials stay server-side. OCR language data is downloaded from the Tesseract data host, but document images are not sent there.
