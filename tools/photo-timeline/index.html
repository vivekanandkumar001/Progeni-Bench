Photo Timeline Builder

Build a chronological photo album with EXIF dates and embedded thumbnails in one HTML file. Zero server uploads — all processing happens directly in your browser.

What it does

Reads EXIF DateTimeOriginal (falling back to the file date), downscales every photo to an embedded data-URL thumbnail (default 400 px longest side), and groups the set by day with sticky headings and per-group counts (automatically switching to month or year groups for large sets). You get a click-to-open full-resolution lightbox, a per-file date-correction field with an EXIF / file / manual confidence badge, a total output-size report, and a single self-contained photo-timeline.html with lazy-loaded images and the original filenames as captions.

How to use

  1. Drop a folder or batch of photo files from a family event, wedding, or holiday.
  2. Each JPEG's EXIF DateTimeOriginal is read first; files without EXIF fall back to the file date and are flagged for correction.
  3. Review the day/month groups, click any thumbnail to open the full-resolution original, and fix any wrong dates inline.
  4. Check the embedded album-size report, add an album title, and download the standalone photo-timeline.html photo diary.

Limits & Considerations

Photo dating prefers EXIF DateTimeOriginal then the file date; EXIF GPS, lens model and facial tags are not read. Thumbnails are re-encoded client-side as JPEG data URLs, so very large sets produce a large single file.

Privacy & Security

Album generation runs entirely in client-side JavaScript. Your personal photo libraries and event memories remain completely confidential.
