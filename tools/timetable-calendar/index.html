About this tool — how it works, limits & FAQ

What it does

Converts class schedules, university lectures, and work shift timetables from simple CSV spreadsheets into recurring weekly iCal (.ics) calendar events. Generates RFC 5545 compliant recurring VEVENT entries with proper time zone formatting and recurrence rules.

Common use cases

  • Class Schedule to iCal Import: Convert weekly school, college, or university class timetable CSVs into calendar events.
  • Shift Work Schedule Generation: Transform rotating weekly work shift spreadsheets into recurring calendar reminders.
  • Fitness & Routine Calendar Planning: Turn weekly exercise class schedules into recurring calendar appointments for Apple or Google Calendar.

How to use

  1. Create a CSV with columns: day, start, end, title (e.g., Monday, 09:00, 10:30, Mathematics Lecture).
  2. Upload the CSV schedule file into the timetable converter interface.
  3. Review the number of recurring calendar events generated by the parser.
  4. Download timetable.ics and import it directly into Google Calendar, Apple Calendar, or Outlook.

Limits & considerations

Generates recurring weekly events for a standard 16-week term. Custom bi-weekly alternating schedules require separate CSV exports.

Frequently asked questions

How should my timetable CSV data be structured?

Rows should include day of the week (e.g. Monday), event name, start time (e.g. 09:00), end time, and optional location or notes.

Does the tool create recurring calendar events?

Yes. It generates standard RRULE:FREQ=WEEKLY recurrence rules so your classes repeat each week throughout the term.

Can the generated .ics file be imported on mobile phones?

Yes. The exported .ics file can be imported directly into Apple Calendar on iOS, Google Calendar on Android, or Outlook.

Privacy & security

Student schedules and employee shift CSVs are parsed locally in browser memory with zero cloud transmission.
